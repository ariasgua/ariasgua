# 🌡️ AVR Temperature Controller

**Technologies:** AVR, FSMs, timers, interrupts, PWM, EEPROM

## Overview

Real-time control firmware integrating temperature sensing, persistent storage, LCD output, a rotary encoder, and configurable threshold control.

## Engineering work

- Implemented FSM-based behavior with timers and interrupts.
- Used PWM for control and EEPROM for stored settings.
- Validated timing and hardware behavior with oscilloscope and multimeter measurements.
