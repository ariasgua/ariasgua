# 🌅 Sunshine Sleep Mask

**Status:** In development  
**Technologies:** ESP32-WROOM-32, KiCad, C++, I2S, LiPo, APA102 LEDs, React

## Overview

Sunshine Sleep Mask is a wearable embedded system combining adaptive illumination, audio feedback, real-time sensing, and behavior informed by physiological sleep data.

## Engineering work

- Designing a custom multilayer PCB around an ESP32-WROOM-32.
- Integrating LiPo charging and protection, DC-DC regulation, a MAX98357A audio amplifier, APA102 LEDs, and peripheral interfaces.
- Developing the embedded system and a companion React interface.
- Validating the design through soldering, board bring-up, and bench measurements.

This page describes an ongoing project. Public design files or source code have not been linked here yet.
