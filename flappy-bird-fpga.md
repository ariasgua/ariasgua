# 🎮 Flappy Bird FPGA

**Status:** In development  
**Technologies:** Verilog, RTL, FSMs, VGA, QuestaSim

## Overview

A real-time FPGA game designed in modular Verilog RTL. The design covers VGA rendering, player movement, obstacle generation, collision detection, and scoring.

## Engineering work

- Building synchronous counters, clock dividers, and debounced inputs.
- Using FSM-based control for game behavior.
- Verifying resets, state transitions, collision boundaries, and timing with directed testbenches and waveform analysis before hardware deployment.

This page describes an ongoing project. Public RTL or testbench files have not been linked here yet.
